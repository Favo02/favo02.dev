Started the rebuild of [favo02.dev](https://favo02.dev). Moving from React + Tailwind to Astro with vanilla CSS.

The focus this time: **typography**. Big text, refined fonts, no transparency effects, almost zero animations. Just content.

Tech stack: Astro 5, vanilla CSS custom properties, GitHub GraphQL API with server-side caching, Content Collections for blog and devlog.
