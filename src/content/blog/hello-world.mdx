# Hello World

This is the first post on the new blog. It's built with [Astro](https://astro.build) and uses Content Collections for type-safe content management.

## Why rebuild?

The old site was built with React and Tailwind. It was heavy, animated, and — honestly — over-engineered for what it needed to be. I wanted something that felt more like reading a well-typeset document than navigating a web app.

## What's different

- **Typography first** — big text, refined fonts, generous spacing
- **Almost no animations** — just subtle color transitions on links
- **Server-rendered** — GitHub data is cached, no client-side API calls
- **Markdown-native** — blog and devlog are just `.md` files

More to come.
